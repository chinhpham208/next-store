# M1 Nền tảng & đường ống — Implementation Plan

> **Cho agent thực hiện:** làm từng task theo `docs/process.md` (một ticket = một nhánh `NS-xx-…` = một PR). Các bước dùng checkbox (`- [ ]`) để theo dõi. Chỉ đọc task của mình và block Interfaces của task liên quan.

**Goal:** Một trang chủ thật chạy trên production (Vercel + Neon), hiển thị 6 sản phẩm nổi bật theo design system đã duyệt (US-01, phần M1), đi qua đủ đường ống: ticket → nhánh → PR → CI → preview → production → E2E trên URL thật.

**Architecture:** Next.js 16 App Router trong `src/`, Cache Components bật từ đầu. `app/` chỉ routing; logic ở `features/`; dữ liệu ở `db/` qua Drizzle. Không có `DATABASE_URL` → PGlite (local, CI); có → Postgres trên Neon qua `postgres` (postgres-js). Truy vấn sản phẩm nổi bật là hàm `"use cache"` gắn tag `products`, nên `/` được prerender tĩnh lúc build và làm mới sau 1 giờ hoặc theo tag.

**Tech Stack** (kiểm bằng `npm view` ngày 2026-11-19): next 16.4.6, react / react-dom 19.3.1, typescript **6.0.3** (7.0.2 chưa dùng được — Task 1 Step 5), tailwindcss 4.3.5 + @tailwindcss/turbopack 4.3.5, drizzle-orm 0.45.4, drizzle-kit 0.31.11, @electric-sql/pglite 0.5.16, postgres 4.1.1, vitest 5.1.1, dependency-cruiser 18.8.0, @playwright/test 1.65.1, @axe-core/playwright 4.14.0, tsx 4.23.15, eslint 9.x + eslint-config-next 16.4.6 (theo scaffold), clsx 2.1.1, tailwind-merge 3.7.0, server-only 0.0.1. Zod 4.6.7 chưa cài ở M1 (chưa có input nào; cài ở M2).

Ngoài bảng công nghệ của `design.md` §2 — **cần chủ dự án duyệt cùng plan (Cổng 1):** `tsx` (chạy script migrate / seed), `clsx` + `tailwind-merge` (hàm `cn()` mà `conventions.md` §6 yêu cầu), `server-only` (`conventions.md` §2).

**Spec:** `docs/requirements.md` (US-01, mục 5), `docs/design.md` (§2, §3, §6, §7, §8, §9), `docs/architecture.md`, `docs/conventions.md`, `docs/process.md`, ADR-0001, ADR-0003, ADR-0005.

## Global Constraints

- Thư mục làm việc: `~/Projects/next-store` (trong máy ảo: `$HOME/mnt/Projects/next-store`). Mọi lệnh chạy từ đây.
- **Mỗi task:** `git switch main && git pull && git switch -c NS-<số>-<hậu tố ghi ở task>` → các bước → lệnh verify → commit (Conventional Commits, mã ticket cuối dòng đầu, kết thúc bằng dòng attribution của phiên) → `git push -u origin HEAD` → `gh pr create` tiêu đề `NS-<số> <tóm tắt>` → review → CI xanh → squash-merge. Không commit thẳng vào `main` (ngoại lệ duy nhất: commit nhập tài liệu ở Task 1 Step 2).
- **Verify:** `bash scripts/verify.sh quick` (typecheck, lint, check:deps, test) hoặc `full` (thêm build, smoke, e2e); mã thoát 3 → `bash scripts/verify.sh wait`. Bước chưa có script in `::skip`. Dán các dòng `::pass / ::fail / ::skip` thật vào PR.
- Không dùng: Pages Router, `getServerSideProps`, `middleware.ts`, `unstable_cache`, `revalidateTag` một tham số, `export const runtime` (Cache Components không hỗ trợ), React Query / SWR.
- Phần được prerender không chứa giá trị đổi theo thời điểm (`new Date()`, `Math.random()`) hay dữ liệu chưa cache (K3).
- Code style theo `docs/conventions.md`: `type` thay `interface`; const arrow function; named export (trừ file quy ước của Next.js); không `any`; không `as` (trừ `as const`); guard clause; `cn()` cho class có điều kiện; không giá trị Tailwind tuỳ ý khi đã có token.
- Chiều phụ thuộc `app → features → db | lib | components/ui`; ngoài feature chỉ import `@/features/<tên>`.
- File chạm DB bắt đầu bằng `import 'server-only'`; script CLI chạy bằng `tsx --conditions=react-server` (K8).
- Giá là số nguyên VND, hiển thị qua `formatPrice`. Giao diện tiếng Việt, `<html lang="vi">`.
- Font: không dùng `next/font/google`. Design system chọn web font thì tự host bằng `next/font/local` (file trong repo, đủ dấu tiếng Việt); không thì font hệ thống.
- Ảnh sản phẩm nằm trong `public/images/`, không tải từ internet.
- Secret không vào repo, log, PR, ticket. `.env.example` đã có sẵn — không ghi đè.
- Migration chạy trước khi code mới lên production (ADR-0005) → migration phải tương thích với code đang chạy (thêm trước, xoá sau).
- Lùi phiên bản, thêm thư viện ngoài plan, lệch ADR → dừng, báo Orchestrator.

## Review Focus

1. **Cache mất hoặc sai mà không ai thấy.** Thiếu `'use cache'` → build lỗi (K3, tự lộ). Thiếu `cacheTag('products')` hoặc `cacheLife('hours')` → build vẫn qua nhưng M5 không làm mới được. (Task 8, test `tags the cache entry…`; Task 9 Step 5 kiểm dòng `○ /  1h  1d`)
2. **Dữ liệu production.** Seed chạy trên production; hoặc deploy Vercel thiếu `DATABASE_URL` nên lặng lẽ dùng PGlite trong container build. (Task 5, test `refuses before any statement when VERCEL_ENV=production` / `…when VERCEL_ENV is unset` trong `src/db/seed.test.ts` và `requires DATABASE_URL on Vercel`; Task 6 Step 9–10)
3. **Clone mới / CI chưa có `.data/`** → `npm run build` vẫn qua nhờ `prebuild` và việc tự tạo thư mục cha (K5); seed chạy lại không nhân đôi dữ liệu. (Task 5, test `seed is idempotent`, Step 7; CI chạy đúng tình huống này ở mọi PR)
4. **Không có sản phẩm nổi bật** → trang chủ hiện "Chưa có sản phẩm nổi bật.", không crash. (Task 8, test `returns an empty array…`; Task 9, test `renders the empty message…`)
5. **Import sai chiều lọt qua** — kể cả khi dependency-cruiser không đọc được file TS do sai phiên bản TypeScript (K9). (Task 2 Step 6: file vi phạm tạm thời phải làm `check:deps` đỏ)
6. **TLS tới DB bị nới lỏng hoặc bị vượt qua** — URL có `sslmode` / `ssl` trùng, rỗng, lạ, `disable` / `prefer`, ký tự điều khiển, hoặc `PGSSLMODE=disable` khiến kết nối tới host không phải local thành plaintext hay chấp nhận chứng chỉ bất kỳ; hoặc chuỗi URL lại được đưa thẳng cho postgres-js. (Task 5, test `refuses … on a remote host before constructing a client`, `ignores PGSSLMODE=disable for a remote connection`, `builds the client from explicit options, never from the URL string`, `rejects the duplicate key in …`, `rejects tab after the scheme …` trong `src/db/client.test.ts`)
   Khi nâng phiên bản `postgres` (đang ghim 4.1.1): kiểm lại bằng listener TLS tự ký rằng `NODE_TLS_REJECT_UNAUTHORIZED=0` vẫn bị từ chối — test hiện chỉ kiểm hình dạng option.
7. **Migrate trỏ tới database khác** — `DATABASE_URL_UNPOOLED` cũ / dán nhầm chạy DDL lên database mà app không dùng (khác host, port, tên database, hoặc tham số `database=` / `user=` trong query đè lên). (Task 5, test `refuses … without printing either URL`, `refuses when both URLs use pooled hosts` trong `src/db/migrate.test.ts`; `drops the unknown parameter database …` trong `src/db/client.test.ts`)
