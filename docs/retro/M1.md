# Retro M1 — Hạ tầng và trang chủ

**Kết quả:** production `v0.1.1` tại https://next-store-iota-silk.vercel.app: trang chủ với 6 sản phẩm nổi bật, cache 1 giờ, E2E US-01 chạy trong CI. Dev: https://next-store-dev-ginpham.vercel.app (nhánh `develop`).

Release: `v0.1.0` (hạ tầng, 2026-11-19), `v0.1.1` (trang chủ, 2026-11-20).

## Điều gì chậm

- **Mạng của môi trường agent.** Container không vào được `api.vercel.com`, `console.neon.tech`, `*.vercel.app`, và proxy chặn GraphQL, tạo repo, xoá nhánh, tạo tag qua API. Mỗi việc phải đi đường vòng: REST thay `gh pr create`, VM của chủ dự án để tạo repo và tag, trình duyệt tích hợp để cấu hình Vercel/Neon, đọc log build và kiểm thử trên URL thật.
- **Đăng nhập và quyền.** Vercel cần chủ dự án đăng nhập trong trình duyệt tích hợp; Neon console cần cấp quyền riêng.
- **Seed production.** Kế hoạch giao cho chủ dự án chạy CLI trên máy riêng; thực tế chạy SQL tương đương qua Neon SQL Editor (kiểm trước trên PGlite) để không ai phải cầm mật khẩu database.

## Vòng review lặp

- NS-27: 2 vòng. `max-w-container-page` không sinh CSS (Tailwind v4 đọc `--max-width-*`), test chỉ so chuỗi class nên không bắt được. Đã thêm test biên dịch `globals.css` thật.
- Các PR khác qua ở vòng 1. Auditor bắt nhiều lỗi thật ở NS-25/31/32 (seed fail-open, TLS bị hạ cấp qua tham số trùng), ở NS-26 ghi 4 mục Medium thành NS-36.

## Leo thang và sự cố

- Vercel Hobby chặn deploy vì tác giả commit không phải tài khoản GitHub của chủ dự án. Sửa: đặt `git config user.*` của workspace theo chủ dự án.
- `scripts/youtrack/ticket.py bug` đọc nhầm mã issue khi summary có `[NS-x]` (NS-35, NS-36, NS-37 bị in thành mã story). Đã nối link bằng tay; sửa trong NS-35.
- Lệch kế hoạch: không có Neon branch `dev` cố định; Dev dùng branch tích hợp tự tạo cho nhánh git `develop` (đã cập nhật `design.md` §7, `architecture.md` §6).

## Đề xuất chỉnh quy trình (chờ chủ dự án duyệt)

1. **Seed production** ghi vào kế hoạch đúng cách đã làm: SQL sinh từ `seed-data.ts`, kiểm trên PGlite, chạy qua Neon SQL Editor nhánh `main`. Thêm script `scripts/seed-sql.ts` để sinh SQL thay vì làm tay.
2. **Bypass secret của Vercel** (Deployment Protection) do chủ dự án tạo và lưu vào GitHub secret trước M2, để E2E và smoke chạy tự động trên preview thay vì kiểm bằng trình duyệt.
3. **Ticket theo dõi phải xong trước M3:** NS-36 (an toàn DB khi deploy). NS-35 (smoke + script YouTrack) và NS-38 (trang 404 tiếng Việt, làm cùng US-05) trong M2.
4. **ADR mới** thay một phần ADR-0006 về Neon branch cho Dev; xác nhận ADR-0005 (đang "Đề xuất").
5. **Release PR** do Orchestrator mở; chủ dự án duyệt bằng lời trong chat là đủ (repo private, không có branch protection).
